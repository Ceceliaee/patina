# 提醒器标准选择器的体积归属

本次用户要求日期、时间和重复选择复用 Quiet Pro。时间入口采用锚定浮层，内部并排组合标准日期和时间组件；共享浮层识别由 `aria-controls` 关联的子浮层，避免选择日期、滚动时间或按 Escape 时误关外层。

## 测量与加载

同一锁文件下以 Node 24.22.1、Vite 8.2.4 和预算脚本默认 gzip 测量。历史发布重建值与前候选来自[上一项决策](2026-11-01-recurring-reminders-bundle-decision.md)，没有再次声称测量发布安装包。

| 指标，KiB gzip | v1.9.11 重建记录 | 前候选 | 当前候选 |
| --- | ---: | ---: | ---: |
| 全部 JS/CSS | 384.91 | 396.52 | 396.92 |
| 初始 JS/CSS | 198.81 | 201.35 | 201.34 |
| Tools | 9.81 | 12.37 | 11.89 |
| Destination detail | 未单独记录 | 8.72 | 7.49 |
| QuietAnchoredPopover | 未单独记录 | 1.31 | 1.47 |
| scheduledTaskPresentation | 未单独记录 | 2.23 | 0.46 |
| QuietTimePicker | 未单独记录 | 合并于任务输入 | 1.95 |

时间组件因新增 Tools 消费者重新独立拆包，旧匹配将 1.95 KiB 错算为未归属 support，导致 support 从限额 6.55 超至 7.97 KiB。恢复时间组件独立归属后，该指标为约 6.02 KiB。日期组件也离开 Destination detail，后者缩减约 1.23 KiB（14.1%）。共享浮层增加约 0.16 KiB（12.2%），用于子浮层命中和焦点隔离。总量比前候选增加 0.40 KiB（0.10%），比发布重建记录增加 12.01 KiB（3.12%）；后一差值包含此前提醒功能，不能全部归于本次改动。初始图比前候选减少 0.01 KiB。

未增加依赖，也未调整 manual chunks。日期、时间组件继续按需加载并跨工具页、历史详情和任务设置复用。退回原生输入会违背用户要求；在 feature 内复制选择器或嵌套监听会增加重复实现。另设异步入口会为一个短表单引入额外加载状态，因此保留现有 feature 边界。体积检查不代表启动耗时测量。

## 限定预算调整

- QuietAnchoredPopover 从 1.36 至 1.53 KiB（增加 0.17 KiB，12.5%），当前精确值 1.466 KiB，缓冲约 4.4%。
- 旧任务输入合并预算 2.32 KiB 拆回 QuietTimePicker 2.04 KiB 和任务展示 0.48 KiB，合计增加 0.20 KiB（8.6%）；各自缓冲均低于 5%。
- Destination detail 从 9.05 收紧至 8.1 KiB，减少 0.95 KiB（10.5%）。
- 总量、初始图、locale、其他页面及未归属 support 上限保持不变，继续执行 3% headroom。

上述局部上限合计收紧 0.58 KiB。最终构建及门禁结果由[执行记录](2026-11-01-reminder-calendar-controls.md)记录。
