# 应用与网站颜色的体积决策

趋势图、排行、时间线和分类管理共用对象原色。显示层在切换主题时需要立即计算图形颜色。图标聚类只在缓存未命中且成功取得图标像素时加载。

## 同环境比较

对照构建使用 `a5241902` 的前端源码，加入与候选相同的 Mini 和工具状态入口改动。两个版本使用相同的 Node 24.22.1、Vite 8.2.4、依赖和生产构建参数。下表按预算脚本的 Node gzip 口径计量。v1.9.11 的数据沿用[既有发布重建记录](2026-11-04-tools-notification-bundle-decision.md)。

| KiB gzip | v1.9.11 历史记录 | 接入前 | 接入后 |
| --- | ---: | ---: | ---: |
| 全部 JS/CSS | 384.91 | 399.35 | 403.94 |
| 初始 JS/CSS | 198.81 | 202.77 | 204.11 |
| 图标缓存与取色入口 | — | 1.96 | 1.19 |
| 按需加载的图标聚类 | — | — | 2.81 |
| 网站备用色／统一对象原色 | — | 0.16 | 0.30 |

总量增加 4.59 KiB（1.15%），初始图增加 1.34 KiB（0.66%）。首次显示使用已有颜色即可。第一次遇到未缓存图标时须加载聚类代码，之后应用和网站复用该模块。以上数据测量传输体积。

## 成本归属

纯 TypeScript 实现复用同一份 OKLab 转换，覆盖代表色计算和 OKLCH 显示适配。构建未引入第三方颜色库。独立导入聚类模块将 2.81 KiB 留在按需加载路径。旧取色器及独立网站备用色实现已移除。图标缓存存储原色，主题切换只重算显示色。

统一对象原色由启动时可见的今日排行及其他页面共用，按初始共享模块计量。图标聚类按独立延迟模块计量，原有未归属模块额度继续适用。总预算由 413 调至 416.5 KiB（增加 0.85%），保留 3% 预留后有效上限为 404.005 KiB。初始图、页面、公共依赖和 CSS 继续使用各自的现有预算。
