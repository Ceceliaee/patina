# 提醒日历规则与标准选择器

范围：将提醒器的重复选项调整为不重复、每天、每周、每月、每年；日期时间采用单一入口展开并排控件。复用 Quiet Pro 组件，移除日期时间输入框图标，创建表单三个字段等宽；两类提醒的创建按钮仅保留文字，并使用标准按钮的内容宽度。

## 边界与处理

- 月度使用原始日期中的日，年度使用原始月日；不存在的日期跳过，不能截断到月底。排期事实由 `src-tauri/src/domain/reminder_schedule.rs` 持有。
- 每周按所选日期的星期重复，修改日期同步修改星期；不提供独立星期选择浮层。
- 已保存的间隔规则仍可读取、暂停、恢复和原样保存；新建下拉不再提供间隔选项。本次不改变表结构或备份格式。
- `ReminderScheduleFields` 只组合标准日期、时间、下拉和锚定浮层。嵌套浮层的点击、滚动和焦点行为由共享组件持有，不能在业务页面另写选择器。
- 保留定时确认后完成、循环确认后排到下一次、稍后提醒保持原始排期基准的行为。
