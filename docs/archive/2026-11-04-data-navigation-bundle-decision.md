# Data 页面切换预算决策

2026-11-04，维护者确认小幅提高 Data 懒加载页面预算，以容纳图表切换时的内容就绪处理。预算从 22.6 KiB 调至 22.8 KiB，增加 0.2 KiB（约 0.88%）；统一 3% 预留余量、启动图、公共依赖与总产物预算不变。

## 测量与归属

使用 Node 24.22.1、Vite 8.2.4 和现有锁定依赖执行生产构建，以预算脚本的 Node gzip 口径测得 Data 为 21.98 KiB。旧有效上限为 21.922 KiB，新有效上限为 22.116 KiB；新预算相对当前产物的缓冲约 3.7%。本次未重建正式发布产物，不更新或推断发布基线。

增量属于 Data 页面导航就绪处理，没有新增依赖。已合并重复的就绪通知 effect、减少重复传参，并让该 feature 的 hook 负责页面完成状态及导航测量。Data 仍通过原有路由懒加载；这些同步首屏判断单独拆包会再引入等待过程，不采用额外动态导入。没有将代码转移至启动入口或公共依赖，也没有可替换的新依赖。

## 验证与边界

调整后 `pnpm run build` 与 `pnpm run check:bundle` 通过。初始 JS/CSS 为 202.23 KiB，总 JS/CSS 为 399.11 KiB；其余 owner 均通过现有预算。此处只确认预算及生产构建，不将它等同于完整门禁或原生桌面性能验收。

具体预算由 [bundle checker](../../scripts/check-bundle-budget.ts) 持有；变更依据见[工程质量预算规则](../engineering-quality.md#52-bundle-长期治理与预算变更)。本记录只覆盖上述预算调整，后续交互修改按其实际风险另行验证。
