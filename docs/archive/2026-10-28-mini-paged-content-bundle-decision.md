## 决策与适用范围

三页 Mini 是已确认的产品能力，需要新增活动快照解析、刷新、图表和详情交互。History 与 Mini 共用时间线规则后，一部分代码从 History 移到共享惰性 chunk。按[工程质量的预算规则](../engineering-quality.md#52-bundle-长期治理与预算变更)，分别调整这些实际 owner 的局部上限，收紧 History，保持初始和总 JS / CSS 上限及 3% headroom 不变。

浏览器存储原语仍在初始加载图中，由精确的 `browserStorage` chunk 持有。归属检查继续拒绝将其移到惰性导出对话框；不通过另造一个同名 `index` 小块绕过入口计量。分类规则固定在 `appClassification`，避免新增 gateway 消费者使它与读取仓储自动合包，失去独立预算。

## 增长来源与减重排查

- Mini 增量属于 `app/mini` 的分页内容、失败重试、当前页刷新、匿名与详情交互，以及窄 DTO 验证。保持原有惰性 Mini 入口，没有将独立窗口组件加入主页面树。
- 时间线算法直接迁移到共享纯模型，History 与 Mini 使用同一份实现；没有保留兼容转发层或复制主页面组件。小时图沿用现有共享组件。
- 没有新增依赖，图标继续直接按需导入，图片使用已有本地缓存。网站归并和颜色规则复用现有 owner。
- 检查过按页异步加载。默认今日页需要统计和图表，活动页也复用相同规则；将这些小组件分别拆成异步入口会引入额外请求与加载状态，不能减少一次完整 Mini 使用所需的规则。当前保持一个小型窗口 owner，工具引擎仍由后端持有。
- 初次构建中分类规则自动合进 session gateway，且浏览器存储被抽成未声明的初始块；通过精确模块归属修正，没有把 Mini 成本转移到 AppMapping 或扩大总预算。

Mini 的新缓冲约 4.8%，History 约 8.2%；共享时间线约 4.3%，浏览器存储使用不到 5% 的缓冲。均继续受 3% headroom 和全图上限约束。

## 后续决策：紧凑且有边界的详情提示

2026-10-28，用户要求缩小分类详情，并让 Mini 的柱状图提示向下完整展开、主界面保持向上展开。分类详情需要随触发元素定位，在窗口边缘调整位置，并保留长名称、键盘和触摸读取。这部分已确认交互由 `MiniActivityContent` 持有，窗口大小与动画不变。

同一工具链与 gzip 口径下，恢复原动效后的 MiniShell 为 8.38 KiB，本次必要定位逻辑精简后为约 8.55 KiB，增加约 0.17 KiB（2.0%）。保留 3% headroom 时，原 8.8 KiB 预算的有效上限为 8.536 KiB。只将 MiniShell 上限调整为 8.9 KiB，新缓冲约 4.1%；其余 owner、入口、CSS 和总量预算不变。

减重排查已移除多余的容器 ref、布局 effect 及重复的分类标题分支，改为元素挂载时的局部定位回调。没有新增依赖、懒加载请求或公共定位模块，也未将 Mini 的定位成本移到主窗口。小时图继续沿用共享图表，其向下布局仅在 Mini 分支启用；滚动条复用 Quiet Pro。对不足 0.2 KiB 的窗口私有增量继续拆包会增加入口和加载状态，因此保留现有加载边界。正式发布基线未变，本次不将构建体积或浏览器验证代替原生性能测量。

更新后生产构建与预算检查通过。初始 JS / CSS 为 198.88 KiB，较动效恢复后的 198.77 KiB 增加 0.11 KiB，来源包括已有共享小时图的 Mini 定位分支；总量从 388.25 KiB 增至 388.53 KiB。两者继续满足原预算，MiniShell 的实测为 8.55 KiB。

## 后续决策：指针移出与提示互斥

2026-10-29，修复分类提示在鼠标移向柱状图后仍残留的问题。`MiniActivityContent` 补齐指针离开触发器和提示后的关闭、移入提示的小间隙保护，以及键盘转入小时图时的互斥。这些是既有详情交互的正确性要求；没有新增依赖、定时器、全局监听器或共享模块。

同一构建口径下，MiniShell 从 8.55 KiB 增至 8.64 KiB，增加约 0.09 KiB（1.1%）。原 8.9 KiB 上限在 3% headroom 后为 8.633 KiB。本次只将 MiniShell 上限调整至 9 KiB，缓冲约 4.2%，保留原 3% headroom 及其他全部预算。实现直接复用现有详情状态与 DOM 引用，没有另建 hover 状态机；额外拆包会引入加载过程，将边界判定移到共享层则会让主窗口承担 Mini 专有逻辑，因此保持现有 owner 与加载方式。正式发布基线不变。

最终 `pnpm run check` 通过，MiniShell 实测 8.64 KiB，初始 JS / CSS 为 198.88 KiB，总量为 388.65 KiB。完整浏览器回归 223 项通过；本次为界面交互修复，未以这些结果替代新的原生性能测量。
