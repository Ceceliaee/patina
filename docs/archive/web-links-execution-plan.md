## 行为与边界

沿用应用关联面板的主项、成员、添加与解除操作。主项名称、图标和颜色来自真实域名；网页原始记录不改写。新子域名独立，手动关联可以跨站，每个域名只能属于一个主项，不允许嵌套或循环。
