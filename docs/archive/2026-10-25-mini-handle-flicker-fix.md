# 迷你窗横条闪帧修复

状态：已完成并归档；2026-10-25。

## 范围与判断

修复横条在面板退出后闪一次的问题，同时保护展开、快速反向、鼠标穿透与焦点。复用 mini owner，Windows 裁剪由平台边界实现；不改变停靠方式、动画时长、数据库或权限。

连续视觉需要同一像素在过渡交接时保持屏幕位置。旧实现虽然保证了 CSS 插值连续，但结束时移动并缩小 HWND，WebView 视口必须重排。125% 缩放实测由 `(1090, 0, 380, 300)` 变为 `(1210, 0, 140, 30)`；新增原生断言在旧产物上失败。此证据证明存在重排交接，不能单独证明每次交接都会发生可见闪帧。

修复采用固定画布与原生矩形裁剪：展开、退出及反向过程中保留面板区域，退出完成后仅保留横条的显示和命中区域。横条始终使用相同的局部坐标。前端同时等待面板和横条的动画，沿用代次、过渡编号与失联超时；不增加定时延迟或第二个窗口。
