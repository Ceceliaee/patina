# Data 趋势周期导航与目的地头部重排执行计划

## 1. 文档定位

本文是一份临时、可勾选、可审计的执行计划，用于改造 `数据` 页中两类趋势模块的时间导航，并规范 `应用趋势 / 网页趋势` 头部的信息顺序。

本计划解决两个相互关联的问题：

1. 用户选择自然周、自然月、自然年或自定义范围后，收起状态下的左右箭头应继续沿当前时间语义导航，而不是直接恢复成 `近 7 天`。
2. `应用 / 网页`、已选对象图标和日期导航目前都挤在右侧；应把对象上下文移到标题之后，把右侧完整留给日期导航及其恢复按钮。

本文已于 2026-07-29 完成实施、验证和对抗式审查，现作为已完成执行记录归档于 `docs/archive/`。

## 2. 第一性原理

### 2.1 时间控件首先表达“当前观察窗口”

一个趋势控件最重要的不是提供多少按钮，而是让用户始终回答三个问题：

- [x] 我现在看的是哪一段时间？
- [x] 左右移动后会去哪里？
- [x] 怎样回到默认时间？

因此，左右箭头的含义必须由当前已应用范围决定：

- `近 7 天 / 近 30 天 / 近一年`：继续表达滚动范围级别的缩短或扩大。
- `第 19 周`：左侧进入 `第 18 周`，右侧进入 `第 20 周`。
- `5月`：左侧进入 `4月`，右侧进入 `6月`。
- `2026年`：左侧进入 `2025年`，右侧进入 `2027年`，但不能进入未来自然年。
- 自定义区间：按原区间包含首尾日期的完整长度平移。

同一个箭头不能在用户看见 `第 19 周` 时暗中执行“恢复近 7 天”，否则视觉标签与行为语义不一致。

### 2.2 “恢复”属于日期导航，不属于标题或对象选择

恢复按钮改变的是趋势的已应用时间范围，因此它必须：

- [x] 与日期标签和前后箭头形成同一控制组。
- [x] 出现在日期导航左侧，而不是标题旁边。
- [x] 只在当前范围可恢复时出现。
- [x] 不通过隐藏占位预留宽度。
- [x] 不改变日期导航最右边界，避免主控件左右跳动。

### 2.3 对象上下文应紧邻模块标题

`应用 / 网页` 决定当前对象类型，图标序列决定当前比较对象。它们回答的是“正在分析什么”，不是“正在分析什么时候”。

因此目标顺序为：

```text
应用趋势  [应用｜网页]  [图标1][图标2][图标3] ...     [恢复] [←] [第 19 周] [→]
```

该顺序也建立了稳定的身份映射：

```text
模式 → 已选对象顺序 → 线条顺序 → Tooltip 顺序
```

无需重新增加图例。

### 2.4 共享组件只共享稳定的形态，不共享 Data 私有语义

`QuietRangeControl` 的稳定职责是：

```text
[上一项] [当前标签] [下一项]
```

它同时服务趋势和热力图，不应知道：

- 什么是 ISO 周。
- 自定义范围如何平移。
- 何时恢复到 `近 7 天`。
- 哪些面板拥有日历弹层。

这些规则由 `features/data` 拥有。`DataTrendRangeControl` 已被上下两个趋势面板复用，正是本轮应扩展的 owner。

## 4. 目标布局

### 4.1 活动趋势

```text
┌──────────────────────────────────────────────────────────────────┐
│ 活动趋势        第 19 周总时长 47h 10m   日均时长 6h 44m       │
│                                  [恢复] [←] [第 19 周] [→]      │
│                                                                  │
│                         趋势图                                   │
└──────────────────────────────────────────────────────────────────┘
```

默认滚动范围不显示恢复按钮：

```text
│                                      [←] [近 7 天] [→]          │
```

### 4.2 应用 / 网页趋势

```text
┌──────────────────────────────────────────────────────────────────┐
│ 应用趋势 [应用｜网页] [A][B][C][D]  [恢复] [←] [第 19 周] [→]  │
│                                                                  │
│ [搜索与对象列表]     [指标]                                     │
│                      [多线趋势图]                                │
│                      [应用热力图]                                │
└──────────────────────────────────────────────────────────────────┘
```

Web Sync 关闭：

```text
│ 应用趋势 [A][B][C][D]                   [←] [近 7 天] [→]      │
```

没有可用对象时：

```text
│ 应用趋势                                 [←] [近 7 天] [→]      │
```

不渲染隐藏图标容器，不预留 22px 空位。

### 4.3 窄窗口

桌面宽度足够时保持单行。宽度不足时允许形成明确的两行头部，而不是重叠或横向滚动：

```text
│ 应用趋势 [应用｜网页] [A][B][C][D][E][F][G]                    │
│                            [恢复] [←] [第 19 周] [→]            │
```

响应式优先级：

1. 日期导航保持完整、可点击、不可被对象图标遮挡。
2. 模式切换与图标保持原始顺序。
3. 图标不缩成不可识别尺寸。
4. 空间不足时整体换行，不压缩标签文字，不制造横向页面滚动。

## 5. 时间范围状态机

### 5.1 滚动范围

| 当前状态 | 左箭头 | 右箭头 | 恢复按钮 |
| --- | --- | --- | --- |
| `近 7 天` | 禁用 | `近 30 天` | 隐藏 |
| `近 30 天` | `近 7 天` | `近一年` | 隐藏 |
| `近一年` | `近 30 天` | 禁用 | 隐藏 |

现有滚动范围快捷路径保持不变。

### 5.2 自然周

- [x] 使用周一到周日。
- [x] 使用 ISO week 与 ISO week-year。
- [x] 左箭头将锚点减 7 个本地日历日。
- [x] 右箭头将锚点加 7 个本地日历日。
- [x] 当前周的结束日期继续截断到今天。
- [x] 当前周禁用右箭头。
- [x] 跨年导航将 `2025-12-29` 按内部 ISO week-year 归入 2026 年第 1 周，但可见标签只显示 `第 1 周`。
- [x] 恢复按钮回到 `近 7 天`。

### 5.3 自然月

- [x] 左箭头进入上一个自然月。
- [x] 右箭头进入下一个自然月。
- [x] 月份偏移使用日历构造，不使用固定 30 天毫秒数。
- [x] 当前月结束日期继续截断到今天。
- [x] 当前月禁用右箭头。
- [x] 正确处理 28、29、30、31 天月份及跨年。
- [x] 恢复按钮回到 `近 7 天`。

### 5.4 自然年

- [x] 左箭头进入上一自然年。
- [x] 右箭头进入下一自然年。
- [x] 当前年结束日期继续截断到今天。
- [x] 当前年禁用右箭头。
- [x] 正确处理闰年。
- [x] 恢复按钮回到 `近 7 天`。

### 5.5 自定义范围

设已应用范围为闭区间 `[startDateKey, endDateKey]`：

```text
spanDays = 包含首尾日期的日历天数
```

- [x] 左箭头将起止日期同时减去 `spanDays`。
- [x] 右箭头将起止日期同时增加 `spanDays`。
- [x] 平移使用本地日历日，不使用 `spanDays × 86400000`。
- [x] 只有完整的新范围不晚于今天时，右箭头才可用。
- [x] 不通过把未来边界截断到今天来改变原范围长度。
- [x] 标签继续显示包含首尾日期的天数，例如 `17天`。
- [x] 恢复按钮回到 `近 7 天`。

### 5.6 弹层打开状态

- [x] 点击中间标签继续打开现有 `QuietDateRangePicker`。
- [x] 弹层内左右箭头只切换选择模式，不移动已应用周期。
- [x] 模式顺序保持 `自定义 → 周 → 月 → 年`。
- [x] 日历月份继续由弹层内部的月份箭头控制。
- [x] 未点击确定前，不改变图表已应用范围。
- [x] 点击取消、外部或按 Escape 后丢弃草稿。
- [x] 点击恢复时关闭已打开弹层、丢弃草稿并恢复 `近 7 天`。
- [x] 弹层关闭后焦点返回范围标签；恢复后焦点留在恢复按钮的合理后继位置或范围标签。
