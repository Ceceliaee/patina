## 增长归属与减重排查

匿名事实的 typed gateway、特殊展示身份和图标查询拦截属于既有 persistence/classification owner；历史与数据页面增加无身份详情、名称和操作限制。SVG pattern 和 CSS 纹理由一个共享模块提供，各图表只传实例 ID。EyeOff 已由现有设置页使用，继续沿用直接图标模块导入，未引入新库、字体、图片、PSL 数据或持久化前端索引。

三页仍沿用现有加载边界；匿名项属于页面首屏事实，延迟读取会使总时长或身份先呈现错误状态。再拆几行匿名条件只会增加请求并搬移体积，不会消除必要逻辑。消息资源仍按语言懒加载，旧操作文案直接替换；未并存两套匿名实现。

启动入口、公共依赖、CSS、语言和其他页面预算保持原值。总预算只增加覆盖必要增量及既定 3% headroom 所需的 2 KiB，未预留未来功能容量。History 与 Data 同样保留约 3% 余量，不把其增长移入初始图。固定性能套件 7 组场景各 5 次通过；相关浏览器首屏测量使用 stub 数据，不冒充真实 SQLite I/O。

## 分轨图标修复补充

2026-09-24 用户截图确认匿名应用分轨错误使用色点，修复为已有 EyeOff。修复后 History 约 18.45 KiB，超过 19 KiB 预算所需 3% 余量约 0.02 KiB。复核为分轨新增必要图标分支，没有新依赖；沿用现有图标和分轨组件，不为压缩数十字节改写普通应用图标解析。History 预算局部调整为 19.05 KiB，保留相同余量规则，其余预算不变。上表保留首次实施测量。

## 微点方案与数据页灰色修复补充

用户选择稀疏微点替换斜纹，并要求匿名趋势及选中项固定灰色。微点仍由一个共享模块提供，无新增依赖；数据页在系列及选项配色入口显式处理匿名身份，避免普通图标备用色覆盖。实测 Data 为 21.74 KiB，超出 22.4 KiB 预算的 3% 余量约 0.01 KiB；局部预算调整为 22.45 KiB，余量规则不变。保留颜色决策在数据页，不为搬移数十字节而将产品匿名规则注入通用图标取色工具。
