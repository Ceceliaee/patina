## 目标与边界

横条与面板是同一个入口的两种形态。用户需要看见它们沿停靠边连续交接；反向输入应改变当前运动方向，而不是重新播放起点。原生窗口必须给退场保留画布，退场结束后才释放面板区域的命中范围。

本次修改由 `domain/mini_window` 拥有目标与完成确认，`app/mini_window` 拥有原生窗口尺寸及会话，`app/mini` 与样式拥有视觉插值。原生目标不随动画帧往返 IPC；前端只确认当前过渡完成。确认携带会话与过渡编号，过期确认不能缩小已重新展开的窗口。前端失联有有界回收，避免永久留下透明大窗口。

沿用 [架构](../architecture.md)、[Quiet Pro](../quiet-pro-component-guidelines.md) 与 [验证规则](../engineering-quality.md#5-默认验证门槛)。保护悬停不抢焦点、拖动、固定展开、浮动、全屏与电源抑制、关闭与 WebView 恢复、内容订阅释放及已删除的菜单和提示框。tracking、持久化 schema 与发布身份保持原契约。测试分组和进程隔离由独立测试优化任务维护；本次修正执行中暴露的场景前置条件和故障注入。

## 对抗式复核

复核范围是本次动画增量及其验收修正，保留工作树中既有的挂件退役和其他任务改动。逐条追踪以下失败路径：

- **快速反向与迟到确认：** CSS 从当前插值反向；相同 pending 状态的普通修订不重置完成等待或原生期限。旧过渡编号不缩小新画布，窗口代次阻止旧 WebView 操作新窗口。
- **退出时机：** 收起意图立即让面板 inert，但保持内容节点及订阅到当前动画结束；原生缩小之后面板区域不再拦截桌面输入。减少动画时无需等待虚假的时长。
- **异常中断：** 拖动、位置与显示环境改变、抑制、关闭及恢复终止旧过渡；前端丢失确认时原生有界回收。偏好保存失败恢复原生目标和过渡，避免半成功状态。
- **资源与权限：** 动画不增加逐帧 IPC、常驻计时器或独立窗口；完成动作沿用 mini 自身的 caller guard。内容订阅按实际可见生命周期释放，长采样和资源循环均已确认相应预算。
- **验收自身：** Tauri 的 invoke 属性不可写，旧故障注入没有生效；改为实际阻塞动画完成，并断言注入被调用。WebView 崩溃用例等待调试端确认注入，再断开调试器，仍以原生失败记录、新窗口代次和恢复内容验收。历史页等待真实 pointer capture 后移动；存储重启仍需新目标和持久化数据佐证。

最终复核未发现未修复的产品问题。跨屏负坐标与 100%、125%、150%、200% 几何有确定性覆盖，真实 Windows 输入验收使用本机单屏 125% 环境；本次没有物理多屏拔插证据。长期窗口契约归架构文档，用户可见行为已记入 changelog；本文仅保留本次执行与验收记录。
