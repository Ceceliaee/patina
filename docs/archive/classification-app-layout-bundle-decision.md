## 排查与取舍

- 复用既有图标、颜色编辑、提示和 badge 原型，没有新增依赖、平行实现或整库导入。
- 六条文案分别拥有状态或失败恢复含义。复用现有动作标签不能完整表达四条状态说明；删除失败也不能复用“原有设置未更改”的保存提示。
- 将新增 schema 项追加到原条目之后，避免重排全部既有资源索引；未改变生成器、加载器或持久化契约。
- 分类实现继续位于 AppMapping 懒加载图，英文和西文沿既有 locale 懒加载。仅为六条短文案拆出异步模块会增加模块与等待状态，不形成有意义的节省。
- runtime 的增量归本地化消息索引；中文默认资源及类型化文案索引的启动成本约百字节量级。未把分类业务实现移入启动图，启动入口与总产物预算均未放宽。
- 新预算只有约 3.1%–3.4% 余量，低于共享/启动类 5% 上限；仅覆盖当前必要体积，不为未来功能预留额外容量。
