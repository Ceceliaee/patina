> 状态：实施与验收完成，已勾选归档。
>
> 创建：2026-10-28；更新：2026-10-29。
>
> 执行范围：独立 Mini 的「今日 / 活动 / 工具」三页、同源只读数据与主界面显示偏好同步。
>
> 当前授权：执行本方案至完成，验证后勾选归档，再开展对抗式审查；未授权提交、推送或远端状态修改。

## 1. 从使用目的推导边界

Mini 的任务是在用户继续使用其他应用时，用一次短暂查看回答三个问题：今天的时间分布怎样、最近一小时在做什么、已启动的计时工具还剩多久。由此推导实现约束：

| 基本事实 | 设计与工程结论 | 可观察的验收结果 |
| --- | --- | --- |
| 悬浮窗占用其他工作的可见面积 | 固定小尺寸，用分页分配信息；详情按需浮现 | 三页均在 320×240 逻辑像素内完成主要阅读，无横向滚动 |
| 用户要快速读数 | 每页只回答一个问题；删去重复状态说明 | 无「正在记录」「空闲 4 分钟」「运行中」常驻底部小字 |
| 相同数据出现两种结果会损害信任 | 复用统计规则、分类身份和显示模式 | 同时间范围、同数据版本下，Mini 与主界面读数一致 |
| 主窗口可能关闭或释放 WebView | Mini 自行读取后端状态，不能依赖主页面组件存活 | 主窗口关闭后，Mini 仍能更新；重新打开主窗口后显示偏好一致 |
| 观察不应改变被观察的活动 | Mini 保持只读，悬停展开不抢前台 | 查看或翻页不暂停 tracking、不修改工具、不改变前台归属 |
| 隐藏页面没有持续渲染价值 | 只刷新可见页所需内容，隐藏时停止内容轮询 | 折叠、切页、关闭后无遗留内容定时器或请求循环 |
| 分类与时长涉及隐私与数据正确性 | 复用匿名、排除、应用关联、域名归并及有效片段口径 | 不能从悬浮提示、图标、辅助标签泄露已匿名身份 |

产品范围以[产品原则](../product-principles-and-scope.md)为准；优先级以[路线与优先级](../roadmap-and-prioritization.md)为准。这里不增加任务管理、生产力评分、联网看板或新的计时工具。

## 2. 已确定的界面合同

### 2.1 尺寸与标题栏

全部设计尺寸均为逻辑像素，不能直接把截图中的物理像素写入窗口配置。

| 项目 | 目标值 / 行为 |
| --- | --- |
| 展开及浮动窗口 | **320×240** |
| Mini 标题栏 | **高 32px** |
| Mini 标题栏按钮 | **24×24px 点击区** |
| Mini 标题栏图标 | **14×14px**，包括状态图标、翻页和右侧操作图标 |
| 主界面右侧标题栏按钮图标 | **统一 14×14px**；主界面原有 38×36px 点击区不在尺寸调整范围内 |
| 页面顺序 | 今日 → 活动 → 工具 → 今日；向左按相反顺序循环 |
| 中部导航 | `‹ 当前页名 ›`；手动切换，页名居中 |
| 左侧 | 现有状态图标与可拖拽区域 |
| 右侧 | 打开主窗口、保持展开、关闭；保持现有动作语义 |
| 折叠态 | 保留现有顶部 112×24、侧边 24×88 逻辑尺寸及三边贴附行为 |
| 页面记忆 | 折叠、关闭重开及应用重启后恢复最近页面；首次默认「今日」 |

标题栏初始布局预算：外框宽 320，扣除两侧边框与各 8px 内边距后约 302px；左右各分配 80px，中部约 142px。右侧三个 24px 按钮加两个 4px 间距共 80px；中部两个 24px 翻页按钮和两个 4px 间距后仍可容纳约 86px 页名。左右等宽保证页名相对窗口居中；左侧状态图标之外的空白可用于拖拽。

边框与标题栏计入总尺寸。按 1px 外框计算，内容区约高 206px；初始内容内边距可取左右 12px、上下 10px，得到约 294×186px 的实际排版空间。内边距与图表高度可以在这个预算内调整，不能为容纳内容擅自放大窗口或缩小已确定的按钮点击区。

| Windows 缩放 | 320×240 逻辑尺寸对应的物理尺寸 |
| --- | --- |
| 100% | 320×240 |
| 125% | 400×300 |
| 150% | 480×360 |
| 200% | 640×480 |

显示器工作区不足时继续采用现有几何约束，将窗口限制在可用工作区；不得让右侧按钮跑到屏幕之外。长语言页名使用合适短标签，必要时省略并保留完整可访问名称，不压缩操作按钮。

### 2.2 各页内容

| 页面 | 常驻内容 | 按需详情 | 不增加的内容 |
| --- | --- | --- | --- |
| 今日 | 「当日活动」、当日累计时长、上方小时柱形图、下方一整条按占比分段的分类横条 | 小时柱：时段、累计时长；分类堆叠模式另含分类明细。分类横条：分类名称、累计时长，可附占比 | 环形图、横条下的常驻分类名称与时长、重复状态页脚 |
| 活动 | 最近一小时的时间线、左对齐的范围累计值、可滚动完整排行 | 时间线片段：对象名称、起止时间、时长；排行仅显示名称与时长 | 独立的应用 / 分类 / 网站模式切换按钮、全量历史明细、常驻范围标题与空闲说明、排行悬浮提示 |
| 工具 | 已启动的番茄钟和计时器的只读读数；有可靠源数据时显示阶段和进度 | 必要的工具阶段、暂停或完成状态 | 启动、暂停、重置按钮，以及重复「运行中」小字 |

没有工具时仍保留「工具」页与简短空状态，例如「暂无运行中的工具」。不因为工具启动、完成或收到 tracking 事件自动跳页。暂停、完成不能伪装成持续运行；其必要状态应附着在对应工具内容上，不恢复全局状态页脚。

活动列表先按最多三项设计，这是本方案的实现默认值。应用模式列应用，分类模式列分类，网站模式列归并后的网站；列表标题、颜色与累计值随同一模式变化。三项之外的数据仍包含在范围累计与时间线中，列表不能暗示只显示的三项就是全部数据。

### 2.3 「跟随主界面」的精确定义

| 信息 | 跟随什么 | Mini 自己保留什么 |
| --- | --- | --- |
| 小时柱形图 | 主界面总量 / 分类堆叠模式；相同分类色、匿名纹理、时长格式和悬浮提示语义 | 适合小窗口的绘图区、刻度密度 |
| 最近一小时时间线 | History 的应用 / 分类 / 网站模式；对象命名、归并、颜色和片段语义 | 最近一小时的窗口范围 |
| 分类占比条 | 主界面分类定义、显示名称、自定义颜色、匿名与归并规则 | 紧凑单条布局，详情悬浮显示 |
| 主题、语言 | 已保存的主题、配色和语言 | 无独立 Mini 设置副本 |
| 当前页 | 不随主界面导航变化 | Mini 自己记忆「今日 / 活动 / 工具」 |

本方案默认「今日」始终指本地当前日期，「活动」指滚动最近 60 分钟；主界面查看其他历史日期、调整时间线缩放或详情筛选不改变这两个范围。该时间范围是本方案明确采用的实现约定，不能把“跟随主界面”扩大解释为跟随全部页面局部状态。

网站记录关闭时沿用主界面的有效模式回退规则；不能一边显示“网站”模式，一边偷偷填入应用数据。恢复网站记录是否恢复旧模式，应与主界面同源规则一致。

## 4. 数据合同与正确性条件

### 4.1 时间、累计与显示

一次内容请求使用一个确定的 `sampledAtMs`。当天范围通过现有本地日期工具得到；最近一小时为 `[sampledAtMs - 3_600_000, sampledAtMs)`，允许跨午夜。不要把本地一天写死为 86,400,000ms，也不要让前后两个查询各自取当前时间。

对经过既有有效性、匿名、排除和归并规则处理的片段，范围内时长为：

```text
durationMs = max(0, min(segmentEndOrNow, rangeEnd, sampledAtMs)
                    - max(segmentStart, rangeStart))
categoryDurationMs = sum(effective durations assigned to the category)
categoryShare = categoryDurationMs / sum(all categoryDurationMs)
```

公式说明范围裁剪，不替代现有数据口径。先由当前读模型确定哪些片段可计入，再做相同边界下的累计。不要把网站活动时长再叠加到已经包含浏览器的应用总时长中。

- 今日累计、小时分布与分类横条来自同一份有效数据。底层保留毫秒精度，只在展示时格式化；逐项取整后的文字之和不作为统计对账来源。
- 占比条按原始时长比例绘制，零数据不计算除零、不伪造四个均分色块。尾端像素舍入只影响绘制，不修改时长。
- 小时柱保留现有每小时视觉上限与余项归并规则。源数据的重叠口径可能使累计超出一小时；不要为配合图高修改真实统计值。
- 聚合记录中用起止值编码的累计量不能当成真实发生区间。近期时间线读取精确片段，显示分钟主对象时沿用 History 规则。
- 时间线像素宽度或“分钟主对象”不能用于反推排行榜时长；榜单由同范围完整有效片段累计。
- 应用关联、网站归并、自定义名称、颜色与匿名规则先解析再展示。列表按时长降序，同值使用稳定身份键排序，不能每次刷新跳位。

### 4.2 只读内容接口

窄命令 `cmd_get_mini_activity_snapshot` 已实现。请求只表达 Mini 页面需要的范围种类，服务端限定为当前日或最近一小时。工具仍使用已有工具投影。

| 快照内容 | 约束 |
| --- | --- |
| 页面 / 范围身份 | 返回范围起止、取样时间；前端确认与当前请求相符 |
| 一致性 | 一次 SQLite 事务读取活动与设置 / 映射，聚合继续消费已有源修订；前端以请求代次拒绝失效返回，不用采样时间冒充数据库版本 |
| 今日数据 | 小时累计与分类分布所需记录，包含活动会话应有的有效部分 |
| 活动数据 | 同范围精确片段；仅网站模式读取所需网站数据 |
| 展示元数据 | 只返回显示所需设置、分类与映射；不暴露 Web token、备份配置等无关设置 |
| 错误 | 区分空数据与读取失败；不以成功的空数组吞掉失败 |

实现复用 data/read-model 的事务快照、源修订及失效机制，将元数据、活动与图标查询放在同一事务中；设置事件使正在读取的请求失效并合并后续重读。新接口不绕过读模型的 dirty / fallback 路径，也不把整个统计查询包进 tracking 状态切换锁。

### 4.3 刷新与错误状态

| 状态 | 要求 |
| --- | --- |
| 首次加载 | 标题栏可操作；内容显示轻量加载态，未就绪前不展示假零值 |
| 成功但无数据 | 显示零累计、空图或简短空状态；没有 NaN、虚构色块或无效 tooltip |
| 同范围刷新失败 | 可暂留最后有效内容，但冻结实时外推；通过现有状态语义或内容内错误提示说明不可用，不显示为新鲜成功结果 |
| 首次读取失败 | 内容内显示简短失败提示与重试；不借此增加常驻页脚 |
| 日期、范围或模式变化 | 旧数据不能配新日期 / 新模式标签；按请求身份接收结果或显示加载态 |
| 旧请求晚到 | 通过请求代次和源版本丢弃，不能覆盖后来页面 |
| 折叠、关闭、主窗口恢复 | 停止不需要的内容工作；重新显示先读最新快照，不靠离线秒表补算 tracking |
| tracking 暂停、工具暂停 | 从真值停止相应外推；切页不改变状态 |

## 5. 实施顺序与可勾选步骤

- [x] **B5 保存页面偏好。** 将页面纳入已有 Mini 偏好、窗口快照和动作链路；只保存本窗口页面，不授予通用设置写权限。旧偏好没有该字段时默认 today，非法值只回退页面字段，保留位置与保持展开偏好。
- [x] **B6 实现翻页。** 添加带可访问名称的左右按钮，支持循环顺序；连点按确定顺序处理，保留现有 epoch / 过期动作保护。保存失败不能让主状态与界面永久分叉。
- [x] **B7 切页清理。** 切页时关闭旧 tooltip、清理页面专用监听和刷新任务；焦点留在触发按钮，不因重新挂载跳到关闭按钮或页面外。
- [x] **B8 检查布局。** 在实际 320×240 viewport 验证三页、长页名和三种贴边方向；固定标题栏无换行、无覆盖、无横向滚动，左侧保留可拖动空白。

出口：三页空壳可切换、可记忆，原生尺寸和前端布局一致；不依赖后续数据接入才能操作标题栏。

### 阶段 C：建立跨窗口显示偏好

- [x] **C1 复用小时图设置。** 将已有 `hourly_activity_chart_mode` 纳入 Mini 必需的只读启动快照；统一解析默认值与非法值，不能在 Mini 写一套不同映射。
- [x] **C2 确定时间线模式 owner。** 在规范应用设置类型、解析和持久化路径中增加 `app / category / web` 模式；建议字段 `historyTimelineMode` / 存储键 `history_timeline_mode`，最终名称按当时命名 owner 确认。
- [x] **C3 迁移旧值。** 主窗口启动时，仅在规范设置确实不存在时读取 `patina:history-timeline-mode`；验证后通过主窗口允许的设置路径保存。读取失败不能当作“不存在”。
- [x] **C4 处理迁移竞争。** 保存采用既有事务或条件写入，避免迟到迁移覆盖用户新选择；规范设置成功保存后清理旧模式值。不得顺带迁移或删除日期分布、时间线缩放等无关偏好。
- [x] **C5 改造主界面消费者。** History 模式 hook 改读规范设置并通过主窗口保存；删除旧模式双写路径，保留网站关闭时现有的有效模式回退。
- [x] **C6 补齐展示元数据。** Mini bootstrap 按最小需要包含自定义分类、应用关联和网站模式所需名称 / 颜色 / 归并信息；沿用分类初始化顺序，分类就绪前不画错色后再跳变。
- [x] **C7 订阅设置变化。** 主窗口保存成功后通过已有设置变化事件使 Mini 失效重读；先订阅再读初值，处理读期间发生的变更。事件作为失效信号，不能让迟到载荷覆盖规范设置。
- [x] **C8 验证主窗口缺席。** 在规范值已存在、主窗口未挂载的情况下创建 Mini，确认模式、主题与分类能够完整恢复；旧版本首次迁移未发生时使用明确默认值，主窗口迁移后自动同步。

出口：两个窗口共享显示偏好的持久化真值；Mini 没有独立模式开关，也没有依赖主窗口内存的镜像状态。

### 阶段 D：接入有界只读数据

- [x] **D1 定义 DTO 与解析。** 按第 4 节写出请求、范围身份、源版本和必要记录结构；TS gateway 严格检查枚举、有限数值、时间顺序和必要字段，错误不能变成有效空快照。
- [x] **D2 实现数据读取。** SQL / 事务留在 `data` 所属仓储与读模型；应用层只编排，command 只接收参数、映射和转发。新的读取复用已有索引与聚合路径，不扫描全历史。
- [x] **D3 分离两种数据。** 今日使用活动聚合来源；最近一小时使用精确会话 / 网站有效片段来源。不得将聚合伪区间投射成时间线。
- [x] **D4 统一时间截点。** 后端捕获一次时间并生成本地日边界与滚动范围；当前活动会话、空闲剔除、暂停和来源修订沿用既有引擎 / 读模型语义。
- [x] **D5 保证版本匹配。** 活动与元数据在同一 SQLite 事务读取，消费现有聚合源修订；前端事件使当前请求失效并合并后续重读，不接受旧请求覆盖新模式。接口失败显示可重试状态。
- [x] **D6 保留异常读取路径。** 验证投影可用、dirty、缺失、修复和 facts / hybrid 回退；结果与主界面使用同一口径，不写第二套“Mini 专用”统计规则。
- [x] **D7 收紧命令权限。** 在命令注册、权限文件及 Mini capability 中添加精确只读入口；按现有 IPC 合同补充允许调用者与拒绝测试，不为方便复用开放通用历史写入或 SQL 权限。
- [x] **D8 避免阻塞状态切换。** 现有 tracking 暂停 / 工具快照的短状态锁不包裹日统计或时间线查询；慢数据读取不能阻塞 tracking 状态切换与窗口收起。
- [x] **D9 控制响应规模。** 今日仅返回绘图所需聚合；活动仅返回最近一小时及其必要元数据。高频切换记录较多时使用现有有界读取 / 编译能力，不能无提示截断后声称总量完整。

出口：无 UI 时也能用合成数据验证范围、总量、匿名、版本和权限；空数据、失败与过期结果可区分。

### 阶段 E：实现今日页

- [x] **E1 建立只读页面模型。** 从同一快照生成累计、小时总量 / 分类分布和分类占比；复用 `hourlyActivityCompiler` 与已存在的分类规则。仅为 Mini 组合所需数据，不加载 Dashboard 的昨日对比与整页图标缓存。
- [x] **E2 复用小时图。** 使用共享 `HourlyActivityChart`，在真实容器宽度下验证柱宽、0/6/12/18 时刻与视觉上限；确需紧凑参数时同时覆盖原消费者，不能复制整套图表。
- [x] **E3 实现单条占比。** 按有效分类累计绘制连续横条，使用稳定分类键、主界面颜色及匿名纹理；没有固定四分类假设。
- [x] **E4 保证小分类可访问。** 保留真实分段比例；键盘 Tab 进入横条后可用左右方向键逐项查看分类。点击或触摸任意分段打开全部分类详情，窄分段也能通过浮层滚动读取；不要求手指准确命中极窄色块。横条不归并或截断分类。
- [x] **E5 接入按需详情。** 悬停、键盘聚焦与触摸可查看分类名称、时长；复用 `QuietChartTooltip` 的视觉与可访问语义，不恢复条下静态图例。
- [x] **E6 覆盖空与失败。** 当天为零时有明确零累计和空图；首次失败不显示假零；午夜换日不能在新日期下留着昨天总量。
- [x] **E7 对账。** 用相同时间截点和源版本比较 Mini 与主界面的小时数据、原始分类累计及总量，再检查格式化文本，不用四舍五入后的标签反算结果。

出口：当日趋势和分类占比在一页内可读，详情只在用户需要时出现，数值可追溯到共同来源。

### 阶段 F：实现活动页

- [x] **F1 提取实际共享规则。** 从 History 的时间线纯模型中提取跨消费者需要的范围裁剪、分钟主对象、相邻片段和身份 / 颜色规则。新共享模块名称与落点按架构确认；迁移 History 与 Mini 两个消费者，避免保留两套算法。
- [x] **F2 复用时间线原语。** 组合现有 `QuietTimelineTrack` 与相关片段原语；History 的日期导航、缩放和整页图例继续留在其 feature，Mini 不导入整页 hook。
- [x] **F3 构建滚动范围。** 始终展示完整最近一小时；无活动的时间保留空白，跨午夜仍连续。刻度标明实际时间，不把片段压缩拼成无空隙占比条。
- [x] **F4 按模式生成内容。** 应用、分类、网站三种模式使用同一有效模式生成时间线、排行和累计；网站排除项、关联域名与匿名记录按现有规则处理。
- [x] **F5 生成完整排行。** 使用完整有效片段的累计并稳定排序，在剩余高度内滚动查看全部对象；显示名截断时不挤压右侧时长。图标只读取已有可用缓存或当前允许的来源，不为 Mini 增加远程图标请求。
- [x] **F6 实现片段详情。** 显示名称、起止时间、时长；跨日时提供日期消歧。隐私字段在进入 tooltip 和辅助名称前完成匿名处理。
- [x] **F7 验证模式实时切换。** Mini 打开时在主窗口切换模式，观察时间线与排行一起更新；读取过程中快速切两次模式，第一次的迟到结果不得覆盖第二次。
- [x] **F8 覆盖近期无活动。** 最近一小时为空但当天有累计时，活动页显示自己的空态；不能回退显示全天排行榜或把空闲解释成读取失败。

出口：条上显示“何时发生”，列表显示“累计多少”，两者来自同一范围而不会互相替代统计口径。

### 阶段 G：实现工具页

- [x] **G1 复用工具真值。** 继续消费已有计时器 / 番茄钟投影和变化事件；不在 Mini 启动第二个工具引擎，不持久化复制工具状态。
- [x] **G2 明确展示顺序。** 默认沿用现有投影顺序：计时器在前，番茄钟在后；同时存在两种工具时两项均可见，切页和工具事件不能调换顺序或自动跳到工具页。
- [x] **G3 补充必要投影。** 如果展示阶段与进度，从现有引擎快照提供阶段和实际目标总时长；用户自定义时长、正计时和没有进度的工具不能套用固定 25 分钟。
- [x] **G4 约束本地外推。** 仅对可信运行态按快照方向更新读数；暂停、完成、源失联和离开工具页时停止，恢复后读取真值校正。保留现有完成态展示期限语义，变更需单独说明理由。
- [x] **G5 完成极端状态。** 无工具、单工具、双工具、暂停、完成、长时长与倒计时到零均可读；不出现负数、跳页、虚构进度或「运行中」页脚。

出口：工具读数来自现有工具体系，Mini 始终是只读消费者。

### 阶段 H：输入、悬浮提示与资源生命周期

- [x] **H1 统一页面活动条件。** 沿用 Mini 展开、过渡、suppressed 和关闭状态；页面切换由单一页面 owner 决定，避免每页各自监听全部事件并各起一套轮询。
- [x] **H2 按可见页读取。** 今日 / 活动只请求各自数据；工具秒级文本刷新只在工具页需要时运行。折叠时停止内容与健康轮询，保留现有必要状态事件，使折叠柄仍能显示状态。
- [x] **H3 取消过期工作。** 合并短时间重复失效事件；维护请求代次，卸载或失活时失效未完成请求；旧返回不能恢复已隐藏页的定时器或 UI。
- [x] **H4 处理 tooltip 边界。** 在 320×240 内测量并翻转 / 偏移 tooltip；底部分类条优先向上展开。最大宽高按窗口内可用空间限制，超长分类详情在浮层内部滚动。Portal 不会突破原生窗口裁剪边界，关键内容须可在窗口内部读到。
- [x] **H5 协调输入保护。** 鼠标进入 tooltip、键盘在图表内导航、触摸打开详情时沿用现有窗口保护机制，避免读到一半自动收起；退出后释放保护，不留下永久展开。
- [x] **H6 处理 Escape 层级。** 有详情层时先关闭详情并恢复触发点；没有详情时继续执行既有收起动作。调整现有 shell 捕获处理，不能让父层先收起窗口。
- [x] **H7 验证拖拽与点击。** 在状态区空白拖拽、在翻页和右侧按钮点击；按钮不触发拖拽，拖拽结束不误翻页。24px 点击区及相邻间距在各 DPI 下可准确命中。
- [x] **H8 保持原生窗口合同。** 悬停展开不激活；主窗口获焦不关闭 Mini；保持展开、屏幕切换和三边贴附仍可用。沿用固定原生画布与内部展开动画的既有生命周期策略。
- [x] **H9 清理资源。** 切页、折叠、关闭及重开后检查订阅、timer、observer、tooltip portal、图标缓存与未完成请求；不靠全局永驻缓存掩盖重复加载。

出口：有数据的三页与原生窗口动作可同时工作，不引入持续后台内容刷新或输入抢占。

## 6. 验收矩阵与确定性样本

| 检查项 | 输入 / 操作 | 通过条件 |
| --- | --- | --- |
| 尺寸 | 四档 DPI、三边贴附与浮动 | 正常工作区下展开逻辑值 320×240；标题栏 32、按钮 24、图标 14；无按钮裁切 |
| 分页 | 连续左右翻页、折叠 / 重开、应用重启 | 顺序正确，恢复稳定页面；工具和数据事件不抢页 |
| 主题与语言 | 两个窗口同时打开后修改主设置 | Mini 原地同步；长文本无错位；匿名纹理仍可区分 |
| 小时模式 | 主界面在总量与分类间切换 | Mini 同步，不出现混合的模式标签与旧数据 |
| 时间线模式 | 应用 → 分类 → 网站；关闭网站记录 | 条、列表和累计采用同一有效模式；回退与主界面一致 |
| 分类变更 | 改名、改色、应用关联、域名归并 | Mini 与主界面一致，无旧名称 tooltip 残留 |
| 稀疏数据 | 当天少量短片段、很窄分类 | 累计准确；短片段与小分类详情可用；不靠强制最小色块扭曲占比 |

| 时间边界 | 跨小时、跨午夜、系统时区 / 时钟变化 | 使用共同时间截点和已有日期 owner；无新日标签配旧日内容 |

| 重叠与归并 | 并行源、相邻片段、同域多个记录 | 沿用现有合并口径；图宽不代替累计；不重复叠加浏览器与网站时长 |
| 异常恢复 | 首次失败、刷新失败、投影失效、删除 / 导入 | 不把失败显示成零；不接受旧版本；恢复后自动读取正确结果 |
| 工具 | 正计时 / 倒计时、番茄阶段、暂停、完成 | 读数和状态符合真值，无默认时长猜测、负值或写操作 |
| 详情交互 | 鼠标、Tab、触摸、Escape、屏幕边缘 | 可打开和关闭，内容不出原生窗口，焦点和窗口保护正确释放 |
| 主窗口缺席 | 关闭 / 释放主 WebView 后操作 Mini | 不依赖主页面组件；打开主窗口入口仍有效 |
