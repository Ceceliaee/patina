## 1. 目标与边界

统一今天、历史、数据、分类、工具、设置、关于七个页面的字重规则，让相同阅读任务拥有一致的视觉强调，让字重由共享来源控制。统一不等于所有文字同样粗，也不等于把当前值全部替换成 600。

本轮只处理字重。已经讨论的字号、行高、字体族、配色、控件尺寸、间距和布局作为固定输入；不通过放大字号、改变颜色或增加留白掩盖字重问题。若字重导致真实裁切，先检查角色是否选错，再单独记录必要的几何修复，不把布局重设计并入本任务。

纳入七页主内容、共享页头、相关弹窗、菜单、按钮、输入框、徽标、状态文字、图表文字和数值。窗口标题栏、侧栏、桌面挂件等共享消费者需要影响检查，但不主动重设计。品牌图片与第三方 SVG 内置文字属于资产，不按普通界面文字批量替换。

长期规范由 [Quiet Pro](../quiet-pro-component-guidelines.md) 持有；实现归属遵循 [架构规范](../architecture.md)；验证遵循 [工程质量](../engineering-quality.md)；语言与文案遵循 [本地化规范](../localization.md)。本文件是临时执行方案，不取代这些 owner。

与 [字号执行方案](./typography-unification-execution-plan.md) 分开验收。实施前先处理两轮改动混杂的问题，不能把尚未恢复的字重误当成字号轮次已确认的结果。

## 2. 从第一性原理推导规则

### 2.1 字重承担什么任务

用户首先需要找到操作对象，然后识别名称与数值，最后阅读说明。字号已经承担页面、板块与内容的尺度层级；字重负责在相同或接近字号内区分重要程度。每增加一个字重，都应对应能被识别的阅读任务，而不是某个页面的局部偏好。

由此得到四个约束：

1. 同角色一致。相同按钮、同类列表名称和同类状态标签跨页面保持一致。
2. 强调有限。标题与关键读数可以更重，但不能让每一行都像标题。
3. 密度稳定。改变字重可能改变字形宽度和换行，不能只检查 CSS 数值。
4. 来源唯一。一个角色的字重修改应落在 token 或共享组件 owner，不依赖多个选择器互相覆盖。

### 2.2 数值一致不代表视觉一致

当前字体栈从 IBM Plex Sans、Segoe UI 到中文及系统回退字体。声明字体族不代表对应字体已经安装或正在渲染；中英文还可能在同一行使用不同字体。不能假定 650 是 600 与 700 的视觉中点，也不能假定 computed style 返回 650 就代表实际存在该字重字形。

执行时要同时检查请求的字重、实际使用的字体、混排效果和最终截图。固定字体环境后比较候选方案，不在本轮引入新字体、字体下载或字体合成策略变化。

### 2.3 统一的评价标准

最终方案应同时满足：标题容易定位，正文可持续阅读，按钮足够清晰，辅助信息不过分抢眼，关键数值可快速扫读。减少字重档位是维护手段；如果所有内容都一样粗而丢失层级，即使数值更少也不算完成。

## 4. 候选字重体系

候选体系收敛为 **450 / 550 / 650 三档**，分别对应正文与辅助信息、内容与普通数值、标题与操作强调。不再采用 400 / 500 / 600 / 700 四档，也不保留 450 到 650 每隔 50 一档的五档方案。以下映射已实施，真实 Windows 缩放和最终美观仍待维护者查看。

| 建议 token | 初值 | 主要用途 | 不应承担的用途 |
| --- | --- | --- | --- |
| `--qp-font-weight-regular` | 450 | 正文、长说明、帮助正文、占比、文件名、图例与坐标标签 | 页面标题、主要操作 |
| `--qp-font-weight-medium` | 550 | 列表名称、设置项名称、输入内容、菜单项、普通状态文字、列表时长 | 需要突出识别的关键读数 |
| `--qp-font-weight-emphasis` | 650 | 各级标题、按钮、badge 徽标、核心汇总与重点数值 | 整个卡片、整段正文、全部列表内容 |

角色映射补充：

- 标题各级统一采用 emphasis，层级由已经确定的字号和位置表达，不增加第四档字重。
- 普通按钮统一采用 emphasis；主次与危险语义沿用现有色彩、背景和边框，尺寸档位不另设字重。
- badge 徽标统一采用 emphasis 650，包括截图中的“未分类”及同类状态徽标；保持已确定的字号、尺寸和内边距。说明性元信息仍采用 regular，未放入徽标的普通状态文字采用 medium。关于页可点击入口由按钮 owner 控制，不因外形相似而改用徽标样式。
- 数据页主要汇总、趋势顶部汇总与核心时长采用 emphasis；列表内的时长采用 medium；百分比与文件名采用 regular。
- 输入内容与 placeholder 同档，placeholder 的区分沿用原有颜色。禁用状态保留所属控件字重，不靠变细表达禁用。
- 选中分段项或菜单项可由 medium 提升到 emphasis，但必须验证切换前后宽度稳定；hover、focus 不改变字重。

关于页按钮用相同字号、尺寸和文字对照当前 600、旧 650 与候选共享 emphasis 650。目标是通过共享按钮角色恢复适当的视觉分量，而不是添加 `.about-pill-action { font-weight: 650 }` 局部补丁。所有尺寸的按钮都要一起复核。

重点验证实际字体能否呈现 450、550、650 的层次，而不是假定中间值必然有独立字形。若三档在实际环境中无法区分，或强调档仍过重，记录证据后整体调整共享映射，不新增局部档位。不得直接覆盖长期文档中当前“标题 600”的约定，最终确认映射后再更新其拥有段落。
