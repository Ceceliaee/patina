# 专注任务详情的体积预算

番茄计时和自由专注共用任务详情，展示每次专注、休息及暂停后的实际计时区间。详情随 Tools 页面加载，按任务读取 SQLite 历史，主窗口导航和工具定时刷新均不预取历史。

## 同环境测量

使用项目锁定的 Node、Vite、依赖及预算检查器的 gzip 口径，对同一个工作区进行两次生产构建。对照构建还原原有任务行、工具页面状态和服务，排除本次界面消息与样式，保留其他同时进行的产品改动。最近正式版 v1.9.11 的历史重建总量为 384.91 KiB，来源见[对象原色预算记录](2026-11-05-activity-color-bundle-decision.md)。

| 指标（KiB gzip） | 对照 | 加入详情 |
| --- | ---: | ---: |
| 全部 JS/CSS | 403.97 | 405.05 |
| Tools 页面 | 13.37 | 14.04 |
| 简体中文消息块 | 9.20 | 9.22 |

净增约 1.08 KiB（0.27%），主要来自 Tools 内的详情展示、读取处理及四种语言的文案。两种模式复用同一详情组件、既有弹窗和图标，没有新增依赖。已移除无消费者的旧页面番茄控件回调与每秒重复构建的摘要。Tools 本身按需加载，独立拆出详情会为第一次点击增加模块请求，不能消除其总产物成本。此测量为产物体积，未推算启动耗时。

## 预算决定

经维护者确认，总预算由 416.5 调整为 417.7 KiB，增加 1.2 KiB（0.29%）。保留 3% 预留，对应有效上限由 404.005 调至 405.169 KiB。此调整仅覆盖总 JS/CSS 预算，各页面、入口、公共模块和 CSS 继续采用现有上限。
