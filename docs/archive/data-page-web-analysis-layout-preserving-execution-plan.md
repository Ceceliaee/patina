## 1. 第一性原理

### 1.1 用户真正要回答的问题

Data 页不是为了展示更多图表，而是帮助用户回答三个稳定问题：

1. **我的总活动量如何变化？**
2. **我的时间主要去了哪些应用；浏览器内部又去了哪些网站？**
3. **这些活动在长期日历中呈现出什么节奏？**

因此，本轮不新增独立“网页统计专区”，而是在现有信息结构中补齐网页观察口径。

### 1.2 应用时间是总活动事实，网页时间是浏览器内部解释

Patina 的应用追踪记录浏览器进程本身；Patina Web Sync 记录浏览器内部的活动域名。

所以：

- 应用时间包含浏览器时间。
- 网页时间属于浏览器时间的内部拆解。
- 网页时间不应与应用时间相加。
- 网页记录不完整时，不应反向修改总活动量。
- “全部活动”继续以桌面应用会话为事实来源。

一句话约束：

> 网页是浏览器时间的下钻视角，不是另一份可叠加的总时间。

### 1.3 现有布局本身是产品资产

当前布局已经建立了稳定阅读顺序：

1. 左上：活动趋势。
2. 左下：活动热力图。
3. 右侧：应用趋势。

本轮的最小正确变化是：

- 左上保持不动。
- 左下保持不动，只增加对象范围控制。
- 右侧保持不动，在原面板内部增加“应用 / 网页”视角。

任何需要增加顶层 KPI 行、移动热力图、把三个区域改成纵向新结构、合并时间范围或新增第四块面板的实现，都超出本执行单。

### 1.4 功能可见性必须服从当前设置

Web Sync 是用户主动控制的能力。

因此：

- Web Sync 开启：右侧面板可以显示“应用 / 网页”切换。
- Web Sync 关闭：不渲染“网页”选项，不渲染禁用态网页按钮，也不发起网页分析读取。
- 设置从开变关：立即回到应用模式，并把网页对象热力图恢复为“全部活动”。
- 历史数据库中即使仍有网页记录，当前关闭状态下也不提供网页入口。

### 1.5 没有记录不等于确认使用为零

当前协议只证明 Patina 收到了哪些网页片段，不能证明扩展在每一秒都在线。

因此网页热力图采用以下诚实语义：

- 有网页片段：显示精确记录时长。
- 当前域名首次记录之前：显示“未记录”。
- 首次记录之后但当日没有片段：显示“未记录到网页活动”。
- 不使用“网页使用为 0”或“确定未访问”之类无法证明的文案。
- 悬浮提示始终先显示完整日期或周区间。

### 1.6 长期分析必须有有界成本

Data 页会读取近一年甚至自定义长区间，不能把所有网页事实行长期搬进 WebView。

因此：

- Rust `data/*` 负责范围查询和按时间桶聚合。
- Tauri command 只做参数接收和 DTO 转发。
- 前端 gateway 只做协议映射和校验。
- Data feature read model 只做页面展示组合。
- 单次请求最多处理 400 个时间桶。
- 超过 400 个时间桶的区间由前端按连续边界分片并合并。
- 默认应用模式不发起网页分析读取。

## 4. 数据口径

### 4.1 名词

| 名词 | 定义 |
|---|---|
| 应用总时间 | 当前分析范围内有效桌面应用会话的裁剪后总时长 |
| 网页记录时间 | 当前分析范围内 Patina 实际收到的网页活动片段裁剪后总时长 |
| 规范化域名 | 小写、去尾点后的域名键，例如 `openai.com` |
| 当前对象 | 右侧面板当前模式下选中的应用或域名 |
| 活跃天数 | 当前对象在范围内记录时长大于 0 的本地自然日数量 |
| 峰值日 | 日粒度下记录时长最大的本地自然日 |
| 峰值月 | 月粒度下记录时长最大的本地自然月 |
| 未记录 | 当前日期早于该域名最早可证明的记录时间 |
| 未记录到网页活动 | 日期在可记录时期内，但没有收到该域名的网页片段 |

### 4.2 时间裁剪

每个网页片段对某个时间桶的贡献必须按交集计算：

```text
贡献时长 =
  max(
    0,
    min(片段有效结束时间, 时间桶结束时间)
    - max(片段开始时间, 时间桶开始时间)
  )
```

其中：

- 已结束片段使用 `end_time`。
- 活跃片段使用 Rust 命令执行时的 `now_ms`。
- 不直接把整段 `duration` 归入开始日期。
- 跨午夜、跨月和跨范围的片段必须拆分。
- 所有前端时间桶边界以本地日期计算后传给 Rust，避免 Rust 猜测 WebView 时区。

### 4.3 网页占比

```text
某域名占比 =
  某域名在当前范围内的网页记录时长
  / 所有可见域名在当前范围内的网页记录时长
```

占比规则：

- 分母只包含网页记录，不包含应用时间。
- 被用户排除的域名不进入分子、分母和列表。
- 分母为 0 时，占比为 0，但界面显示空状态，不显示误导性排名。
- 百分比只用于网页列表内部比较。

### 4.4 用户分类设置

Data 页必须复用现有网页域名语义：

- `displayName`：作为列表显示名。
- `enabled: false`：从常规统计、搜索、指标、图表和热力图隐藏。
- `color`：本轮不用于大面积 UI；保留为未来分类语义，不改变面板 chrome。
- favicon：只作为识别辅助，读取失败不阻塞数据。

### 4.5 应用与网页不相加

- [x] 活动趋势继续只使用应用会话。
- [x] 全部活动热力图继续只使用应用会话。
- [x] 网页总时长不进入活动趋势总时长。
- [x] 网页列表不与应用列表混排。
- [x] 不提供“应用 + 网页”的合计数字。
- [x] 不提供会让用户误以为网页是额外时间的文案。
- [x] 网页模式的指标标题优先使用“网页记录时长”等可解释文案。

### 5.1 页面状态

```text

selectedDomain: string | null
appSearchQuery: string
```

```text

```

### 5.2 状态转换矩阵

| 事件 | 右侧模式 | 当前对象 | 热力图范围 | 网页读取 |
|---|---|---|---|---|
| 首次进入 Data | 应用 | 默认应用 | 全部活动 | 不读取 |
| Web Sync 开启，切到网页 | 网页 | 既有有效域名或首个域名 | 保持当前范围 | 读取当前右侧范围 |
| 网页模式切回应用 | 应用 | 既有有效应用或首个应用 | 当前对象时跟随应用 | 停止新增网页读取 |
| Web Sync 关闭 | 应用 | 保留有效应用选择 | 强制全部活动 | 不读取 |
| 搜索过滤掉当前对象 | 当前模式不变 | 第一个匹配对象 | 当前对象时跟随新对象 | 按需 |
| 搜索无结果 | 当前模式不变 | 空 | 强制全部活动 | 不追加对象热力图读取 |
| 当前对象被排除 | 当前模式不变 | 第一个可见对象或空 | 无对象时全部活动 | 失效缓存 |
| 当前范围变化 | 当前模式不变 | 尽量保留有效对象 | 热力图范围独立不变 | 网页模式按新范围读取 |
| 热力图年份变化 | 当前模式不变 | 不变 | 保持当前 scope | 只有当前网页对象时读取 |

### 5.3 非法状态收口

- [x] `webActivityEnabled === false && destinationMode === "web"` 必须收口为应用模式。
- [x] `selectedDomain` 不在可见域名中时，选择首个可见域名或 `null`。
- [x] `selectedAppKey` 不在可见应用中时，沿用现有应用选择规则。
- [x] `heatmapScope === "selected"` 但没有有效对象时，收口为 `all`。
- [x] 迟到的网页 Promise 不得覆盖已经切回应用模式或已经变更范围的结果。
- [x] 清理缓存后，旧请求完成不得重新把旧快照写回缓存。

## 7. IPC 聚合契约

### 7.1 请求

新增 typed command：

```text
cmd_get_web_activity_aggregate_range
```

前端业务入参：

```ts
interface WebActivityAggregateRangeInput {
  startMs: number;
  endMs: number;
  bucketBoundariesMs: number[];
  normalizedDomain?: string | null;
}
```

Raw Tauri 参数继续服从现有命名与序列化边界。

### 7.2 返回

```ts
interface WebActivityAggregateRecord {
  normalizedDomain: string;
  bucketStartMs: number;
  durationMs: number;
}

interface WebActivityDomainCoverage {
  normalizedDomain: string;
  earliestRecordedStartMs: number;
}

interface WebActivityAggregateRange {
  records: WebActivityAggregateRecord[];
  domainCoverage: WebActivityDomainCoverage[];
}
```

### 7.3 最小数据原则

返回值不得包含：

- URL。
- path、query 或 fragment。
- 页面标题。
- 浏览器客户端 ID。
- 原始片段 ID。
- 逐片段开始和结束时间。

只返回 Data 页所需的：

- 规范化域名。
- 时间桶起点。
- 桶内裁剪后时长。
- 域名最早可证明记录时间。

### 7.4 输入校验

- [x] `endMs > startMs`。
- [x] 边界数组至少包含两个值。
- [x] 第一个边界等于 `startMs`。
- [x] 最后一个边界等于 `endMs`。
- [x] 边界严格递增。
- [x] 单次请求最多 400 个时间桶。
- [x] 域名过滤值经现有域名归一化规则处理。
- [x] 空域名过滤值被拒绝或收口为无过滤，行为必须固定并测试。
- [x] 所有错误返回稳定、可测试的人类可读错误。

### 7.5 长范围分片

- [x] 前端先生成完整本地自然日边界。
- [x] 每个请求最多携带 401 个边界，即 400 个桶。
- [x] 相邻请求共享边界端点，但时间区间不重叠。
- [x] 合并后记录按域名、桶起点保持稳定顺序。
- [x] coverage 合并时取同一域名最早时间。
- [x] 任一分片失败时整次快照失败，不展示部分总计。
- [x] 分片请求支持 in-flight 去重。

## 10. 风险与回滚边界

| 风险 | 预防 | 回滚单位 |
|---|---|---|

| 迟到请求覆盖当前状态 | cancel token / epoch | 回滚缓存层 |

| 样式债务扩张 | 新样式只进 feature CSS | 回滚页面局部样式 |
