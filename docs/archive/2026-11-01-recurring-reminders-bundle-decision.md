# 循环提醒的体积决策

范围是已确认的统一时间入口、间隔/每日/每周提醒、状态图标和编辑功能。新增代码由 Tools feature、原有 IPC gateway 和共享浮层 owner 持有，没有新增运行时依赖。

## 加载与复用

时间入口使用共享浮层和原生日期、时间输入；重复入口、编辑和列表共用循环规则及格式化。浮层新增可选焦点约束，保证编辑弹窗中的 Tab 不跳出选择器。两个提醒到点弹窗仍各自按需加载。循环控件是工具页首屏的一部分，另建异步片段会增加首次选择的加载和焦点分支，保留 feature 内同步加载。

移除旧时间模式后，日期控件被构建器归入 DestinationDetailDialog，剩余时间控件消费者归入 scheduledTaskPresentation。二者的增长是现有控件归属变化。尝试固定 manual chunk 会连带吸入公共依赖，因此保留自动拆包，按实际 owner 调整预算匹配；不修改其他页面功能。

## 预算决定

- 总量预算从 408 调整至 410 KiB，增幅 2 KiB（0.49%）；保持 3% headroom，有效上限 397.70 KiB，不增加额外长期缓冲。
- Destination detail 从 8.1 调整至 9.05 KiB，当前 8.72 KiB，局部缓冲约 3.8%，承接日期控件代码。
- QuietAnchoredPopover 从 1.21 调整至 1.36 KiB，当前 1.31 KiB，约 3.8% 缓冲，覆盖可选焦点约束。
- 原时间控件 2.1 KiB 与任务展示 0.48 KiB 合并归属为任务输入 2.32 KiB，当前 2.23 KiB；合计上限收紧 0.26 KiB。
- 初始图、公共依赖、CSS、locale、Tools、两个提醒到点弹窗和未归属 support 预算保持原值。
