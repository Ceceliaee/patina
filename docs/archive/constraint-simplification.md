## 规则取舍

根入口不再展开视觉状态、前后端层级和产品非目标等母文档细节。Git/Issue 动作授权、提交大小例外仍由根入口完整持有。工程质量第 2—4 节保留维度、优先级、命名版本事实和结构判断，删除同义铺陈。

纯文档默认不运行应用构建、browser 或 Rust 全套；必须检查改动事实、链接、编码和义务。治理/验证政策变化追加文档自检与受影响规则的正反场景；真实检查器、模板或操作说明变化还要验证对应使用路径。前端行为、Rust、架构实现边界、依赖、运行时、发布和 CI 原有门槛继续适用，package/CI 不改。

技能保留任务触发和必要特殊知识；重复的行为指导合并成结果要求。外部接受、退休、动态消费者与复杂交互的细节仍按需引用，不将所有任务强制套入同一表格。删去对每次局部措辞修改都跑全量行为对比的要求；大范围触发/权限改写仍跑相关回归。

## 验证记录

本轮以开始时的精确快照为比较基线，不以 Git HEAD 混入上一轮治理或其他任务的改动。按 UTF-8 解码后的字符数统计，包含空白，非模型 token 数：

| 范围 | 修改前 | 修改后 | 减少 |
|---|---:|---:|---:|
| 根入口 | 17,431 | 9,825 | 43.6% |
| 工程质量 | 11,881 | 11,148 | 6.2% |
| 七个技能正文（含原 frontmatter） | 41,261 | 17,112 | 58.5% |
| 技能引用与模板 | 45,743 | 44,501 | 2.7% |

技能 Markdown 正文连同引用、模板合计减少约 29.2%，没有通过把正文整体移到 references 伪造减少。根入口不再重复领域细节；一处普通文案修改无需固定命题清单、模板、分类报告，也不默认跑应用聚合检查。真实风险场景继续读取相应 owner 和专门证据。这些是文本与政策变化，不是已测得的模型速度收益。

独立审查发现并修正四类残留：操作事实 reference 仍要求运行每个展示命令；证据报告仍要求逐条固定标签；prose reference 仍强制命题枚举；两个 eval 仍强制清单或模板方法。已改为验证受影响事实、复用有效证据、按需记录和结果导向断言。另将稳定期修复的重复验证入口改为链接工程质量 owner，避免文档分支重新分歧。

实际验证：

- `npm run check:docs:self-test`、`npm run check:docs`、`git diff --check` 通过。
- 仓库外静态检查覆盖 29 份 Markdown、145 个相对链接、UTF-8/BOM/替换字符、锚点与围栏；七个技能通过系统 quick validator，89 个 eval 定义可解析且 ID 唯一。
- 89 个提示经过覆盖审查；实际完成 28 个定义内决策模拟和 4 个额外对抗模拟，共 32 次。没有观察到决策层硬失败；不能写成“89 场景执行通过”。新增场景区分普通文案、验证政策和伪装成文档的 Rust caller-guard 改动。
- 实际仓库外文档样例要求只改语法：原句已正确，结果保留原文，关闭弹窗清除明文与禁止预取两项义务均保留，UTF-8/内容核验通过。没有为制造 diff 而改写。
