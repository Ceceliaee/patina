- [x] 用户确定规则：全部自动合并，继承累计使用时长最长域名的分类。
- [x] 用户确认手动升级后，更改目录、重启后的路径及历史数据正常；此反馈不代表 ARM64 或在线 updater 验收。
- [x] 在现有 Rust 迁移入口承接分类，首次升级与已升级数据库均适用。
- [x] 保留已有新版组设置及独立例外；迁移只运行一次，后续清除分类不被恢复。
- [x] 复用历史累计时长口径，时长相同按域名字典序决定；最长域名未分类时保持未分类。
