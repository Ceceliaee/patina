# 循环提醒实施记录

状态：功能实施完成；验证结果与两项未消除的门禁限制如下。归档日期：2026-11-01。

范围：实现已确认的统一日期时间浮层、无确认按钮的重复选择，以及时间后的 repeat / clipboard-check 图标。

## Owner 与行为

- `features/tools` 持有表单草稿、浮层和本地化展示；复用 Quiet Pro 控件。
- Rust `domain` 持有间隔、每日、每周的排期规则；仓储持有确认、稍后提醒及暂停的原子写入。
- 循环规则与首次时间锚点持久化。完成本次后安排严格晚于当前时间的下一次；稍后提醒保留周期锚点。
- 未确认时只保留一个待处理提醒，睡眠或关机错过多次不生成弹窗积压。每日、每周按本地日历安排。
- 新增按提醒 ID 关联的循环状态表，旧提醒保持一次性语义；备份合并保留规则和锚点，已有目标记录优先。
- 使用限制弹窗移除旧提醒内容灰条；历史数据或测试数据携带 message 时也不再显示。
- 不做使用拦截，不改变计时器、番茄钟或使用限制规则；不提交或推送。
