# 产品与优先级

Patina 面向长期使用 Windows 桌面的个人，自动记录活动，让用户回看、校正并掌控自己的时间数据。核心追踪可以在本地独立使用。本文先界定产品承诺，再说明如何为已准入的工作排序。

## 用户与范围

自动采样应正确处理前台切换、AFK、锁屏、睡眠和中断恢复。视频、会议等低交互场景通过可解释的参与信号判断。用户能回看今日活动、历史和趋势，管理应用和网页分类、标题记录和匿名设置，并通过本地数据库、导出、备份、恢复和清理控制自己的记录。

核心体验保持低打扰。用户可以手动校正或主动使用轻量工具。团队报工、组织权限、企业计费、项目管理、游戏化和社交排名超出当前个人桌面工具的范围。移动优先、同步扩展多个平台、账号与云优先服务，以及缺少高频价值的复杂 AI 分析，均须重新评估产品方向。

核心追踪与回看无需账号或网络。Web Sync 向本机接收端提交网页观察，标题受隐私设置控制。选择 WebDAV 备份时，快照按用户的配置传往指定服务。两条路径分别遵循[本机协议](web-sync-protocol.md)和[备份与恢复约定](architecture.md#备份与恢复)。

## 身份、隐私与历史

应用关联允许用户把多个程序归入一个主程序。保存后，历史与后续统计统一使用主程序的名称、图标、分类和颜色；原始程序身份与记录保留，解除后恢复独立展示。排除与标题记录开关仍分别作用于原程序，删除记录也只删除明确选定的程序。

网页按可注册主域名自动分组，新出现的同站子域名自动加入。组内列出实际域名，用户可以将某个完整域名独立显示，再通过“合并到主域名”恢复。组名称默认主域名，图标采用组内保留历史累计时长最多且具有图标的具名成员；组名称、分类和颜色可以单独设置。独立成员恢复自身设置，原始记录不变。无法可靠识别主域名的地址保持独立，私有托管平台按租户边界分组。

组级标题与匿名开关作用于当前成员，新成员沿用自身默认设置。删除组历史须确认当前有记录的成员数量及域名，不包含独立成员；单个域名删除保持精确范围。旧网页手动关系和旧组专属展示设置在保留恢复副本后移除，原始历史和域名自身设置保留。

用户删除的历史不能因刷新、重启或升级重新出现。网页关联与清理保留原始域名的数据控制边界；持久化、管理入口与恢复规则见[架构中的网页关联契约](./architecture.md#网页关联与历史清理)。

匿名统计：所选应用或网页域名继续记录实际活动时间，新增匿名事实不保存身份或标题；既有具名历史从常规统计隐藏，恢复追踪后重新显示。匿名期间不可还原，也不补回旧版本漏记的区间。所有匿名来源作为一个“匿名活动”参与排行、占比和总时长，保留真实时间边界。管理规则与既有具名历史分别保留，不属于匿名事实。

## 工具与提醒

允许在长期信息架构中保留 `Tools / 工具` 页面，用于承载用户主动打开、操作、观察状态的轻量本地桌面工具，例如提醒或番茄钟。

这类能力的默认边界是：

- `Tools / 工具` 放主动操作型能力
- `Settings / 设置` 放偏好配置型能力
- 工具到期提醒属于用户主动启动后的默认反馈，不在 `Settings / 设置` 暴露开关
- 工具页的“工具设置”集中配置提醒与专注共用的通知方式和提示音，选择后立即保存；不加入任务默认时长或全局关闭提醒开关
- 默认使用 Patina 独立软件通知，出现时不拉起主窗口、不抢前台焦点；用户也可选择沿用主窗口内的提醒弹窗。两者复用提醒内容和业务操作，不使用 Windows 系统通知
- 提示音可选择默认、轻铃、清脆或无；选择音色并保存成功后试听一次对应的到期提示音。“无”不试听，只关闭声音，保留到期反馈
- 工具页不替代自动追踪主路径
- 工具页不扩张成任务管理、项目管理、日程系统、团队协作或游戏化生产力平台

## 提案准入

提案应能说明它为当前使用者改善了记录可信度、可读性、自动化或本地控制中的哪一项，如何保持主路径清晰，以及长期收益能否承担维护成本。实现应能落在[现有架构的职责与边界](architecture.md)内。弱相关、低频或依赖未来规模的方向可以延后。需要改变隐私边界、目标人群或产品形态时，由维护者决定是否改变方向。

## 优先级

已准入的事项默认按以下顺序安排：

1. 追踪、统计、数据安全与信任风险。不可逆的数据丢失、误删和错误恢复优先。
2. 高频主路径或发布、启动被阻塞的问题。
3. 已经反复引发回归、阻碍修复或妨碍发布的结构问题。
4. 帮助用户理解记录、顺畅完成日常操作的核心体验改进。
5. 低频增强和实验性想法。

判断相对顺序时考虑使用频率、影响人数和范围、风险能否逆转、前置依赖、长期维护收益和机会成本。同一风险层级内可以参考工作量。明显错误记录、备份与升级风险、主路径严重回归或反复制造缺陷的结构边界，可以打断当前主线。外观微调、纯整理与为未来规模预建的系统通常延后。

用户群、产品范围、阶段或长期取舍发生变化时更新本文。具体任务的进度按[文档生命周期](documentation.md#工作记录与归档)记录。
